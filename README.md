# Evaluating-Vision-Transformers-for-Ordinal-Diabetic-Retinopathy-Classification-on-Fundus-Images
Comparative deep learning study benchmarking EfficientNet and Swin Transformer for five-class diabetic retinopathy severity classification on retinal fundus images (APTOS 2019 dataset), evaluated with Accuracy, Macro-F1, and Quadratic Weighted Kappa.

1. Overview
This report presents a comparative deep learning study for five-class diabetic retinopathy (DR) severity classification from retinal fundus images. Two transfer-learning architectures were evaluated under an identical protocol:
•	TF-EfficientNet — convolutional baseline
•	Swin Transformer-Tiny — hierarchical shifted-window self-attention
Objective: Determine whether transformer-based visual representation learning improves retinal disease classification relative to a convolutional baseline.
